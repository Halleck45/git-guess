For everyone who writes Conventional Commits

Never argue about feat vs fix again.

You write the subject. git guess reads the diff and writes the type, the way your project would have written it. One 7 MB binary, no account, no API key, and nothing ever leaves your machine.

Your changelog stops lying.

    
Release notes, semantic versions and “what changed” summaries are only as good as the types behind them. When every commit carries the right one, the tooling you already have finally tells the truth. No more fix that was really a feature, no more chore hiding a breaking change.

  

  

    
It speaks your repository's dialect.

    
Some teams say chore for CI changes, others say ci. Some bump dependencies as build, others as chore. git guess indexes your last thousand commits and looks at how you named the changes closest to this one, which files they touched, and what you tend to call what. It suggests your convention, not somebody else's.

  

  

    
Pull requests labeled before anyone reads them.

    
One line in a workflow and every pull request gets enhancement, bug or documentation from its diff, plus a note on any commit whose declared type the code contradicts. Reviewers open the PR already knowing what kind of change it is.

    
- uses: Halleck45/git-guess@v1

  

  

    
It admits when it doesn't know.

    
Whether a three-line patch is a fix or a refactor is a question of intent, and the diff does not carry intent. So git guess keeps a calibrated confidence: above 90% it is right 96% of the time. Below 55% it asks, once, in one keystroke, instead of guessing silently.

    
? fix 41% or refactor 38%? [f/r, Enter keeps fix]

  






  
70% right on the first try and 88% within two, measured on 36 projects it had never seen, each commit scored with only the commits before it. Trained on 488,000 commits from 244 open-source projects. Your project's number is one command away: git guess eval.






  
Install in one line.

  

    
    
    
  

  

    
brew install Halleck45/tap/git-guess

    
curl -fsSL https://raw.githubusercontent.com/Halleck45/git-guess/main/install.sh | sh

    
go install github.com/Halleck45/git-guess/cmd/git-guess@latest

  

  

    

      
See what to expect on your project

      
git guess eval

      
Replays your last 200 commits and scores itself against what you actually wrote.

    

    

      
Then forget about it

      
git guess hook install

      
git commit -m "add login" becomes feat(auth): add login. A plain git commit opens your editor with the type already there. Uninstall in one command, skip once with GIT_GUESS_HOOK=0.
